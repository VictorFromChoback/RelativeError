# Relative experiments

This repository contains code for conducting experiments demonstrating the operation of optimization methods,
in particular RE-AGM for relative inaccuracy.

# Tools

The repository contains tools for optimization research.

Folder __src__ contains optimization functions and algorithms - STM and RE-AGM.

# RE-AGM

The file __NesterovCorrected/comparison_solo.ipynb__ provides a way to demonstrate how random relative noise for RE-AGM works on a specific function.

# PEP

PEP comparison of STM and RE-AGM provided at __PEP/estimation_seq/nesterov_est_2.ipynb__ and __PEP/stm/stm.ipynb__.
